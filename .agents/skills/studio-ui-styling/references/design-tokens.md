# Design Tokens & Utilities Reference

---

## 1. Studio Color Tokens

```css
--bg-main: #09090b;       /* App background */
--bg-card: #121215;       /* Card background */
--bg-panel: #0d0d10;      /* Sidebar and panels */
--border-subtle: rgba(255, 255, 255, 0.06);
--border-hover: rgba(255, 255, 255, 0.15);
--accent-primary: #6366f1; /* Indigo */
--accent-purple: #7c3aed;
--status-online: #10b981;  /* Emerald */
--status-busy: #f59e0b;    /* Amber */
```

---

## 2. Typography Rules

- Standard Body: System San Francisco / Segoe UI / Roboto (`font-sans`).
- Numbers / Timers / Specs: JetBrains Mono / Fira Code / Consolas (`font-mono`).
- Headers: Semi-bold with tight letter tracking (`tracking-tight`).
