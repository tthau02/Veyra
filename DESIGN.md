# AI Video Studio — macOS Design System

## Design Philosophy

The application MUST follow Apple's macOS Human Interface
Guidelines and native macOS application design principles.

The target platform is macOS desktop.

This is NOT an iOS application.

The UI must feel like a native professional macOS application.

Visual references:

- Finder
- Final Cut Pro
- Logic Pro
- Photos
- Xcode
- System Settings
- Safari

The application should feel:

- Native
- Premium
- Minimal
- Professional
- Calm
- Spacious
- Functional
- Consistent

Avoid:

- iOS-style mobile layouts
- Material Design
- Bootstrap dashboards
- Generic SaaS dashboards
- Excessive rounded cards
- Excessive gradients
- Neon AI aesthetics
- Heavy shadows
- Huge buttons
- Mobile-style bottom navigation
